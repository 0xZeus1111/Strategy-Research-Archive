结构化摘要：

原文分析一个名为 PB USDC USDT v4a100 的 Curve USDC/USDT 池。该池表面上像普通稳定币池，但 USDC rate oracle 会根据调用上下文返回不同 rate。常见离线 eth_call 报价环境中，gasPrice = 0 或 tx.origin = address(0) 会触发 48 bps 折扣分支，使 USDC 在 quote 中看起来更便宜；真实交易上下文返回正常 market rate。

主要风险方向：

- USDT -> USDC 是 toxic direction。
- eth_call 下 get_dy(1000 USDT) 显示约 1002.988043 USDC。
- transaction context 下同向输出约 998.222250 USDC。
- 差异约 -47.52 bps。
- 反方向 USDC -> USDT 的符号相反，eth_call 反而低估交易上下文输出。
