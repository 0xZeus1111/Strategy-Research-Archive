## 原文标题

加密市场最浅的宝藏：RWA永续套利

## 原文正文整理

文章用复盘方式讨论 `RWA` 类永续合约套利。目标读者是已经理解永续合约基本机制的个人或机构交易者。作者认为，这套模型不仅可以用于价差和资金费率交易，也可以转化成 `Fair Price` 辅助定价框架，服务于 maker 类型交易。

### 1. RWA 永续为什么容易出现机会

作者认为，`RWA` 永续的机会来自传统资产市场和加密永续市场之间的错配。

- `RWA` 永续的指数规则通常来自线下报价商，例如 `dxFeed`、`massive`、`iTick`、`Pyth` 等，指数成分被单点操纵的概率相对低。
- 相比很多加密原生长尾资产，`RWA` 永续的流动性往往更充沛，做市商可以在传统交易场所对冲。
- 传统资产有拆分、派息、财报、换月、宏观事件等波动来源，容易在永续合约和底层资产之间制造时间、规则与流动性错配。

作者的核心判断是：传统市场是连续价格发现，永续合约是带规则约束的衍生品市场，两者之间天然会出现可交易的结构差。

### 2. 美股 RWA 合约的“周一时刻”

作者以早期 `Bitget` 美股合约为例，尤其提到 `MU` 和 `SNDK`。

当时周末没有外部指数 feed，合约主要由 `markPrice` 跟随。为了保护用户体验，资金费率上限较低。若周末出现新闻并导致标的预期价格大幅变化，合约价格可能明显偏离上一个外部收盘价，但资金费率成本被限制在较低水平。

因此作者使用的交易结构是：

- 在周一美股夜盘开启、外部 index 恢复之前开仓；
- 等外部指数报价恢复后，价差逐步回到接近 0；
- 成本主要是封顶资金费率、手续费和滑点；
- 收入来自周末错位价差的回归。

评论区里有读者追问另一条腿在哪里。作者补充：周末是 `Bitget` 合约和 `Hyper` 之间出现几十个基点级别的价差，两边都是永续合约。另有读者问热门美股价差和资费套利是否应主要在交易时间做，作者回应：盘中清仓比较好。

### 3. 原油波动率和资金费率机会

作者回顾今年三四月份原油交易活跃时，`CL` 和 `BZ` 成为 RWA 永续里的明星标的。

当时机会主要来自：

- 原油本身高波动；
- 交易所之间低手续费、流动性尚可；
- 永续指数在换月时逐步 roll 到下一主力月；
- 周末资金费率冻结或延迟反应导致“周一时刻”；
- 可用 `CME`、`CFD`、`MT5` 或其他 RWA 永续作为对冲腿。

作者也提到，真实执行会遇到 `USD` 与 `USDT` 之间互换、券商入金、香港银行卡等操作摩擦。其后续关注方向包括 `Binance bStock` 和 `Bitget rToken`：如果这些资产可以作为合约保证金，就可能提高吃费率和对冲交易的资本效率。

### 4. 海力士案例

作者说，最近一个月主要在做海力士相关交易。

核心观察包括：

- 韩股海力士在盘中资金费率很高；
- 不同交易所的费率规则差异明显，`Binance`、`Bitget`、`OKX` 的参数设置和方向可能不同；
- 晚间美股 `MU`、`SNDK` 会影响相关 RWA 合约价格，使费率成本估算出现偏差；
- 海力士 `ADR` 上市后，`Bitget` 盘前合约较早开放，早期溢价约 `4%`，之后扩大到约 `23%`；
- 如果保证金可以共用，交易者可以在风控规则内提高杠杆和资金效率。

作者给出的支持因素包括：韩国外汇与跨市场转换约束、美股新上市热门板块的买盘力量、外资机构卖韩买美的调仓需求、早期多美空韩的费率净收入，以及台积电 `ADR` 溢价作为参照。

评论区里有读者表示自己在 `4%` 溢价时用高杠杆开仓，但在 `12%` 平掉，作者回应这是错过了后续机会。

### 5. 文章结论

作者认为，`RWA` 套利不是消灭不确定性，而是在规则研究、对冲和仓位管理之后，把自己放到下行可控、上行开放的位置。

## 评论区关键补充

### 1. 盘中清仓更稳

对于热门美股 RWA 合约的价差和资金费率交易，有读者问是否主要在交易时间做。作者回复：盘中清仓比较好。

这一点意味着作者并不把这些交易当成无风险长期持仓，而是倾向在外部报价和流动性最可验证的窗口完成收敛。

### 2. 周末价差不是只能用券商对冲

有读者不理解周一外部 index 恢复前如何吃价差。作者补充，周末价差来自 `Bitget` 合约与 `Hyper` 合约之间，两边都是永续合约。

这说明该案例更接近跨交易所 RWA 永续价差交易，而不是单纯的“加密合约 vs 传统券商现货”对冲。

### 3. 评论区对“套利”定义有分歧

有评论认为，这更严格地说是价差交易而不是套利；也有人指出里面仍然带方向风险，不算纯套利。

这些评论很重要：文章使用“套利”这个词，但实际交易里包含指数恢复时间、流动性、费率、盘口滑点、周末新闻和对冲腿错配，因此不能被理解为无风险套利。
