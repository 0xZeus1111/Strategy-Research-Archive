## 原文标题

大模型是专利期十个月的制药生意

## 原文在讲什么

作者用 DeepSeek 梁文锋提到的“API 定价按十个月回本”作为入口，提出一个关于大模型产业的结构判断：

**大模型企业不是拥有长期专利的传统软件公司，而更像专利期只有约十个月的制药公司。模型发布后，只能在很短窗口内享受高定价权；一旦更强、更便宜的替代模型出现，价格必须快速下调。**

作者认为，这个十个月不是单家公司自由选择的回本目标，而是产业迭代节奏反推出来的约束。

## 核心逻辑整理

### 1. 十个月回本对应模型定价权窗口

作者提到 DeepSeek 的 API 定价逻辑：买一批设备回来，用十个月左右赚回硬件投入。

他进一步把这个数字连接到硬件折旧和 `$/Watt` 范式：

- GPU 如果按五年折旧，六倍利润和十个月回本是同一件事；
- 英伟达在产业链上大约拿走 `$35/W`；
- 按十个月回本反推，DeepSeek 当前约为 `$42/W·yr`；
- Anthropic 可能高于 `$70/W·yr`，甚至更高；
- 云厂商硅盈利效益约在 `$20-30/W·yr`。

作者的结论是：DeepSeek 的生态位虽然未必能承担最贵的机房，但盈利能力已经超过普通云厂商。

### 2. 十个月不是 DeepSeek 的选择，而是产业节奏

作者认为，大模型发布后约十个月内，往往会出现推理成本更低、能力更强的替代品。

这个替代品可能来自：

- 竞争对手；
- 自家公司；
- 架构改进；
- 新训练数据；
- 新训练方法；
- scaling law 继续推进。

关键不在归因，而在结构：模型产业整体以很快节奏淘汰旧价格。

作者用多个例子说明模型溢价窗口非常短：

- `GPT-4` 发布八个月后被 `GPT-4 Turbo` 以更低价格替代；
- `Gemini 1.5 Pro` 几个月内降价；
- `Claude 3 Opus` 很快被更便宜、更强的 `Sonnet` 系列压制；
- `o3` 上线两个月后大幅降价。

模型可以长期服务流量，但高价溢价窗口会快速消失。

### 3. 大模型定价窗口类似摩尔定律

作者把大模型定价权窗口类比为摩尔定律。

他的重点不是“模型也遵守十八个月规律”，而是：

**时间表不是某一家公司决定的，而是整个产业链竞争和协调后的结果。**

摩尔定律曾经从观察变成产业协调机制，企业、设备商、材料商围绕节点节奏排产。大模型没有正式的 `ITRS`，但公开基准、开放权重和透明定价形成了类似机制。

模型厂商不需要签协议，也会被竞品能力、开源模型和价格压力逼着降价。

### 4. 大模型更像短专利期制药公司

作者认为，大模型定价权掉落在结构上类似药品专利到期：

- 新药刚上市时拥有高价格；
- 专利期结束后仿制药出现；
- 价格崩塌；
- 药企必须不断研发下一款药。

区别是，大模型的“专利期”不是十年，而可能只有十个月。

因此，大模型公司面临一种高风险生意：

- 如果新一代模型失败，就可能没有下一个溢价窗口；
- 如果旧模型继续服务流量，会占用训练新模型的算力；
- 如果模型定价权消失得太快，训练投入难以回收。

### 5. 两个可证伪判断

作者提出两个结构性预测。

第一，很多大模型玩家会退场。

原因是非头部厂商很难同时做好训练和推理：

- 训练和推理争夺同一批 GPU；
- 用旧模型赚钱，会占用训练新模型的资源；
- 模型溢价窗口太短，训练投入未必回收；
- 最终可能只有少数头部厂商能同时拥有先进模型和 API 产品。

第二，中国模型不必完全追上美国，就能改变美国模型的定价权。

作者认为，如果中国模型能力略低但价格显著便宜，就可能压缩前沿模型的高价窗口。开放权重的真正作用不是简单抢份额，而是缩短领先模型的“专利期”。

他把目标从“追平美国”改写为：

**把差距压缩到三到六个月，并把美国前沿实验室的定价权窗口压到更短。**

## 评论区关键补充

### 1. 推理算力是压缩定价权的约束

有评论指出，即使中国模型能力接近、API 标价低很多，如果推理算力不足，也无法真正压低美国模型定价权窗口。

作者同意这个限制，并补充：开放权重的作用之一，就是解决模型训练出来后没有足够算力部署的问题。新云厂商和云服务商需要决定手里的 GPU 应该服务谁的推理需求。

### 2. 药品类比可能不完全成立

有评论指出，大模型之间替代效应强，用户需求高度异质。中国模型的机会可能来自能力饱和：只要能满足大部分任务，就能成功。

这意味着，大模型不一定必须在全部能力维度上追平前沿模型，只要在足够多任务上达到“够用且便宜”，就可能压缩高端模型的商业定价权。

### 3. 纳什均衡论证需要更细化

有评论质疑“领先一代或同时出发”这两个纳什均衡的论证不够完整，认为在不同收益矩阵下可能存在其他均衡。

作者回应说，这个棋局中有许多玩家，并不只是双方博弈。

这条补充提示：原文的博弈论表述更像结构性直觉，而不是严格形式化证明。
